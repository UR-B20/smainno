# Reference slides

Drop the exported slide images here, named:

    <project-id>-<slide-key>.png

The showcase looks each one up automatically and shows it beside the screen it
documents. A file that isn't here is simply not rendered — no broken image, no
code change needed to add one.

## Expected filenames

### digital-ips
- digital-ips-intake.png        FormSG intake form
- digital-ips-register.png      SharePoint / Teams case list
- digital-ips-deliberate.png    Deliberation
- digital-ips-coordination.png  Downstream coordination
- digital-ips-dashboard.png     Dashboard view

### fua-tracker
- fua-tracker-overview.png      Overview
- fua-tracker-my-subtasks.png   My Subtasks
- fua-tracker-post-update.png   Post Progress Update
- fua-tracker-raise.png         Raise New FUA

### smartcheck
- smartcheck-checker.png        Checker, reporting an issue
- smartcheck-issues.png         Issue tracker
- smartcheck-dashboard.png      Admin dashboard
- smartcheck-builder.png        Template builder
- smartcheck-schedules.png      Schedules & notifications

PNG or JPG both work — change the extension in `src/showcase/SlideRef.tsx` if
you use JPG.
